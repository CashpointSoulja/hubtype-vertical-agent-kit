# Jobs to be done

## Hubtype's buyer (mid-market ops/CX lead)
- When customers message us on WhatsApp with messy, multi-part problems, I want an agent that holds the whole conversation, so resolution doesn't depend on headcount.
- When the agent is out of its depth, I want the human who picks it up to already know everything, so my customer never repeats themselves and my team trusts the handoff.
- When I evaluate tools, I want a price on the page and a launch measured in days, so I can say yes without a procurement project.

## Hubtype (the company)
- When we look at growth, we want vertical solutions we can sell repeatedly, so revenue stops depending on one-off enterprise projects.
- When Aries asks for LatAm/NA expansion, we want packaging that travels, so new regions don't need new services teams.

## The end customer (Sofia in the demo)
- When something stressful happens, I want to explain it once, in my own words and voice notes, so I can get on with my day.
