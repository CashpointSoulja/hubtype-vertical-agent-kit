# Jobs to be done

## Hubtype's new buyer: mid-market ops or CX lead
- When customers message us on WhatsApp with messy, multi-part problems, I want an agent that holds the whole conversation, so resolution doesn't depend on headcount.
- When the agent is out of its depth, I want the person who picks it up to already know everything, so my customer never repeats themselves and my team trusts the handoff.
- When something must go to a human (injury, vulnerability, a regulated topic), I want that to be a rule I set, not a hope, so I can sign off on compliance.
- When I evaluate tools, I want a price on the page and a launch measured in days, so I can say yes without a procurement project.

## Hubtype, inside Aries
- When we plan growth, we want vertical solutions we can sell repeatedly, so revenue stops depending on one-off enterprise projects.
- When we expand into LatAm and North America, we want packaging that travels, so new regions don't need new services teams.

## The claims handler (Marta in the demo)
- When a conversation lands on me, I want one card with the story, the evidence and the reason it's mine, so I can act in the first message.

## The end customer (Sofia in the demo)
- When something stressful happens, I want to explain it once, in my own words and voice notes, so I can get on with my day.
