# Hubtype Vertical Agent Kit (unofficial concept)

A product concept built to show how I'd approach forward-deployed product work on Hubtype inside the Aries group.

**Live demo:** see the deployed link (GitHub Pages / Cloudflare). Open `index.html` directly for a local run; append `?autoplay=1` for the self-playing version used in the walkthrough video.

## What's here
- `index.html` - the full demo: WhatsApp vertical agent journey + agent workspace handoff + mid-market packaging page + evidence.
- `assets/` - Hubtype's literal logo (scraped from hubtype.com CDN).
- `docs/` - the full PM package:
  - `PRD.md` - problem, solution, scope, stories
  - `ELI5.md` - the plain-English version
  - `FIVE_WHYS.md` - root cause
  - `JTBD.md` - jobs to be done
  - `METRICS.md` - north star + guardrails
  - `TEST_PLAN.md` - tests and results
  - `VIABILITY.md` - why this maps to the seat
  - `ROADMAP.md` - v2
  - `DESIGN_SCRAPE.md` - brand scrape and visual guide
  - `EXPLAIN_IT.md` - the 3-line version
