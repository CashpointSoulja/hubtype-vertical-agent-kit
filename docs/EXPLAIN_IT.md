# Explain-it card (say it cold)

**What it does:** A WhatsApp AI agent that holds a messy, multi-part customer conversation in one thread - claim, policy change, voice note - and hands to a human with the full story when confidence drops.

**How it works:** Cross-intent state carries entities through the journey; a confidence policy (injury, regulated topics, sentiment) triggers handoff; the human gets a structured context card, so the customer never repeats themselves.

**Why it matters:** Hubtype's own reviewers say complex issues still fall over, and only enterprises can buy it (no pricing, 6-8 week launches). This is Aries' stated Hubtype roadmap (https://www.aries.global/newsroom/aries-acquires-hubtype-conversational-ai) - verticals, voice, new GTM - in one working concept.
